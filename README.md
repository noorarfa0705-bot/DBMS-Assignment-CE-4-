# Care Home & Inmate Welfare Dashboard

CE 4 project, M S Ramaiah University of Applied Sciences
Name: Noor Arfa | Reg. No.: 25SSDS415045

A small Python program with a Tkinter window and an SQLite database.
It stores care institutions, their inmates and the care given to each inmate.

## Features
- Three linked tables: institutions, inmate_records and care_provisions
- Foreign keys with ON DELETE CASCADE
- Insert Panel to add a new record
- Delete Panel to delete an institution, an inmate record or a provision
- Four tabs: a combined JOIN view plus each table
- Checks for blank fields and wrong amounts

## How to run
1. Install Python 3 (Tkinter comes with it).
2. Open Care_Home_Dashboard_25SSDS415045.ipynb in Jupyter.
3. Run the cells from top to bottom. The last cell opens the window.

Or run: python care_home_dashboard.py
